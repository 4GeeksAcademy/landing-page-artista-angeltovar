# Landing Page Arkharm

Landing page promocional de Arkharm, un artista ficticio de hip hop underground venezolano. El proyecto presenta una experiencia visual de una sola página enfocada en identidad urbana, navegación clara, accesibilidad y estructura semántica.

## Descripción

La web está construida con HTML y CSS puros. Su objetivo es mostrar al artista, resumir su trayectoria y destacar próximas presentaciones en una interfaz responsive, con una estética oscura y un enfoque fuerte en contenido legible.

## Secciones principales

- Inicio con carrusel visual de bienvenida.
- Sobre mí con presentación del artista y propuesta musical.
- Trayectoria con resumen narrativo y línea de tiempo.
- Próximas presentaciones con eventos programados.
- Navegación fija y acceso rápido para volver al inicio.

## Características destacadas

- Estructura semántica con header, nav, main, section y footer.
- Diseño responsive adaptado a escritorio y móvil.
- Menú hamburguesa en pantallas pequeñas sin usar JavaScript.
- Carrusel animado controlado solo con CSS.
- Accesibilidad básica con enlace de salto, navegación por teclado, foco visible y textos alternativos en imágenes.
- Metadatos SEO y etiquetas Open Graph/Twitter para compartir la página.
- Datos estructurados en JSON-LD para artista, sitio web, álbum y eventos.

## Tecnologías utilizadas

- HTML5
- CSS3

## Cómo visualizar el proyecto

Como es una página estática, puedes abrir index.html directamente en el navegador o levantar un servidor local simple.

Opción 1:

- Abrir index.html en tu navegador.

Opción 2:

```bash
python3 -m http.server 5500
```

Luego abre en el navegador:

```text
http://localhost:5500
```
